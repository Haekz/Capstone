Cómo funcionan los mensajes y qué pasa con tus datos
  • Para qué sirven: solo para coordinar las clases. No se usan para otra cosa.
  • Filtro automático: un programa revisa cada mensaje antes de enviarlo y bloquea teléfonos, correos, redes sociales y direcciones, para que todo se converse dentro de LBWUS. No es infalible. Ninguna persona lee los mensajes por este filtro.
  • Quién los puede leer: {% if rol == 'apoderado' %}tú y el profesor. El profesor ve «Apoderado de» y el nombre de pila de tu estudiante, no tu nombre{% else %}tú y {% if rol == 'profesor' %}el alumno o su apoderado{% else %}el profesor{% endif %}{% endif %}. El equipo de soporte de LBWUS solo puede leer una conversación si alguien la reporta, únicamente desde el ticket, y queda registrado quién la abrió y cuándo. El administrador no puede leerlas.
  • Avisos: cuando llega un mensaje nuevo te avisamos con la campanita y un correo que no incluye el mensaje.
  • Cuánto tiempo se guardan: se eliminan solas cuando pasan {{ dias }} días sin mensajes, salvo que haya clases por dictar, un paquete vigente entre ustedes o un ticket abierto. Si una conversación se reporta, se conserva mientras soporte la revisa; después un líder de soporte decide si se libera o, solo si hay un reclamo, el requerimiento de una autoridad o una investigación, se conserva más tiempo, con revisión cada {{ meses }} meses.
  • Tus derechos: puedes pedir ver, corregir o eliminar tus datos escribiéndonos desde Ayuda y soporte, o pedir eliminar tu cuenta.
